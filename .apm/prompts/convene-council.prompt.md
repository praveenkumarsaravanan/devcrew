# Convene Council

Run council planning for the user's request without implementing changes by default.

1. Read the user's request and identify the likely task size, risk, and council depth.
2. Use the Council Chair perspective to produce a concise Council Brief.
3. Identify the active councils and the specialist agents or instructions they would use.
4. If the request is ambiguous, high-risk, or design-heavy, generate two or three viable options.
5. Compare options with a compact trade-off matrix.
6. Recommend a path and explain the rationale.
7. List risks accepted, risks rejected, required follow-ups, and where user approval is needed.
8. Do not edit files, create branches, run implementation, or produce code unless the user explicitly says to proceed.

Output:

```text
Council Brief:
Options considered:
Trade-off matrix:
Recommendation:
Risks and approvals:
Next step:
```
