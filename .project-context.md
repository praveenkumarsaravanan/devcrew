## Architecture Overview

DevCrew is an APM package that distributes an AI engineering team as Markdown primitives. It contains no runtime code — every agent, skill, instruction, prompt, and hook is a `.md` or `.json` file that the AI reads and follows.

The system follows a three-tier distribution model:
- **Tier 1 (DevCrew):** Universal engineering standards, distributed via APM.
- **Tier 2 (Team packages):** Org-specific standards; can live in `teams/` monorepo or separate repos.
- **Tier 3 (Project):** `.project-context.md`, `.memory.md`, and project-level overrides.

Core workflow (`team-workflow`) right-sizes tasks into quick-fix / standard-change / full-feature and activates only the phases that add value. Eleven specialized agents are dispatched as isolated subagents to prevent self-agreement bias.

## Technology Decisions

- **Pure Markdown** — No runtime, no SDK. Markdown is LLMs' native format and works across Cursor, Copilot, and Claude Code.
- **APM for distribution** — Microsoft APM compiles `.apm/` source to IDE-specific targets. Single source, three outputs.
- **Three-tier memory** — Active (`.memory.md`, ~150 lines), domain overflow (`.memory/<domain>.md`), quarterly archive. Keeps active context concise.
- **PROSE specification** — Progressive Disclosure, Reduced Scope, Orchestrated Composition, Safety Boundaries, Explicit Hierarchy.

## Notes

- APM does not natively deploy `.prompt.md` files to `.cursor/commands/`. The `scripts/post-install.sh` workaround copies them manually. Track: https://github.com/microsoft/apm/issues
- APM scripts are not automatic lifecycle hooks — `apm run postinstall` must be invoked explicitly.
- APM v0.9.2 introduced self-deployment of local `.apm/` content during `apm install --target cursor`.
- Codex CLI is a supported APM target (`codex` in `apm.yml`). Skills, agents, hooks, and MCP deploy; instructions compile to `AGENTS.md`. Prompts/commands are unsupported on Codex — workflow entry points must use skills or agent invocation.
- Codex hooks use PascalCase command handlers (`PreToolUse`), not Cursor's camelCase prompt hooks. `apm run postinstall` (project) or `apm run install-global` (user scope) runs `scripts/setup-codex-hooks.sh`, which overwrites APM's invalid Codex hook deploy. File-edit hooks (`afterFileEdit`) are not available on Codex yet — only Bash `PreToolUse` is wired for the security guard.
- The eval suite covers 5 behavioral dimensions + skill output quality. Standard ML metrics (Accuracy, Precision, Recall, F1, MAE) and Capability/Regression Levels provide rigorous measurement.
